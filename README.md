## 🚀 Run the Notebooks

```bash
git clone https://github.com/Awaneesh03/Machine-learning-.git
cd Machine-learning-

python3 -m venv .venv && source .venv/bin/activate
pip install numpy pandas matplotlib jupyter
jupyter notebook
```

Or open any notebook directly in **VS Code** or **[Google Colab](https://colab.research.google.com)**.
